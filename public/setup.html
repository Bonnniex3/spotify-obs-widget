Spotify OBS Widget

Local setup — nothing here leaves your machine.

1 Create a Spotify app

  1. Open the Spotify Developer Dashboard and click Create app.
  2. Name it anything. For Redirect URI paste exactly: http://127.0.0.1:8888/callback
  3. Tick Web API, save, then copy the Client ID.

2 Canvas video — optional

Canvas clips are vertical 9:16 videos. The widget turns one a quarter turn and uses it as the background of the whole bar.

Fetching them from Spotify automatically is deprecated and the widget no longer tries.

Drop your own clip at public/canvas/<trackId>.mp4 and it becomes the background for that track. The track ID is the last part of a Spotify track link — from open.spotify.com/track/2VEFILxPIsvijHQtwWSVU9 the file would be 2VEFILxPIsvijHQtwWSVU9.mp4. Vertical clips look best, but anything works.

Every other track shows animated, blurred album art instead — no setup needed.

3 Waveform audio — optional

The waveform is a real spectrum of whatever is actually playing — Spotify exposes no audio data, so the server captures an audio device with ffmpeg and analyses it. Pick the device that carries your music (a loopback / virtual cable / "stream mix" device, not a microphone).

4 Build your OBS URL

In OBS: + → Browser → paste the URL, set the size to match, and tick Shutdown source when not visible. Leave Custom CSS empty.
